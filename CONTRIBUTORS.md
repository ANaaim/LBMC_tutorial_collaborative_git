# Contributors 🌟

This file lists all the wonderful people who have contributed to this learning repository. Add your name here as your first pull request!

## How to Add Yourself

1. Fork this repository
2. Create a new branch: `git checkout -b add-my-name`
3. Add your information below in the format shown
4. Commit: `git commit -m "Add [Your Name] to contributors"`
5. Push: `git push origin add-my-name`
6. Create a Pull Request

## Format

```markdown
- Your Name - @your-github-username - Optional: Brief bio, interests, or what you're learning
```
