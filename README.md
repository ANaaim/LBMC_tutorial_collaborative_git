# LBMC Git Collaboration Tutorial 🚀

Welcome to the LBMC Git Collaboration Tutorial! This repository is designed to help newcomers learn how to collaborate on documents using Git and GitHub through hands-on practice.

> **Inspired by collaborative tutorials from Ipuch**

## 📚 What You'll Learn

- Creating and working with Git branches
- Making commits with meaningful messages
- Creating and managing Pull Requests (PRs)
- Reviewing and merging code
- Resolving merge conflicts
- Collaborating with others on shared documents

## 🎯 Quick Start

1. **Read the Tutorial**: Start with [GETTING_STARTED.md](GETTING_STARTED.md) for Git basics
2. **Follow the Exercises**: Work through [TUTORIAL.md](TUTORIAL.md) for hands-on practice
3. **Add Yourself**: Make your first PR by adding your name to [CONTRIBUTORS.md](CONTRIBUTORS.md)
4. **Learn More**: Check out [RESOURCES.md](RESOURCES.md) for helpful resources

## 🤝 How to Contribute

This repository is specifically designed for learning! We encourage you to:

1. Fork this repository
2. Create a new branch for your changes
3. Make your changes (add your name, fix typos, improve documentation)
4. Submit a Pull Request
5. Respond to review comments
6. Celebrate when your PR is merged! 🎉

## 📖 For Complete Beginners

Never used Git before? No problem! Start here:

1. Install Git on your computer: https://git-scm.com/downloads
2. Create a GitHub account: https://github.com/signup
3. Read [GETTING_STARTED.md](GETTING_STARTED.md)
4. Follow along with [TUTORIAL.md](TUTORIAL.md)
