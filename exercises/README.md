# Beginner Git Exercises 🎯

This folder contains hands-on exercises to practice Git skills in a safe, learning-focused environment.

## Available Exercises

### 1. Collaborative Story (`collaborative-story.md`)
**Skill Level**: Beginner  
**What You'll Practice**: Basic branching, commits, pull requests

Add to a creative collaborative story! This is a fun way to practice making contributions.

**How to do it:**
1. Read the story so far
2. Create a branch
3. Add 1-3 sentences continuing the story
4. Commit and create a PR

---

### 2. Team Tips (`team-tips.md`)
**Skill Level**: Beginner to Intermediate  
**What You'll Practice**: Contributing to structured documents, collaboration

Share your Git tips and learn from others!

**How to do it:**
1. Think of a useful Git tip you've learned
2. Create a branch
3. Add your tip in the appropriate section
4. Include an example if possible
5. Commit and create a PR

---

### 3. Practice Fixing Mistakes (`practice-fixing.md`)
**Skill Level**: Beginner  
**What You'll Practice**: Code review, attention to detail, making corrections

This file contains intentional mistakes for you to find and fix!

**How to do it:**
1. Read through the file carefully
2. Find the intentional mistakes (spelling, grammar, facts, formatting)
3. Create a branch and fix them
4. Commit with a descriptive message
5. Create a PR explaining what you fixed

---

## Creating Your Own Exercise

Want to add a new exercise? Great! Here's how:

1. **Think of a skill to practice**
   - What Git concept is tricky?
   - What would help others learn?

2. **Design the exercise**
   - Make it hands-on
   - Include clear instructions
   - Define what success looks like

3. **Create the file**
   - Use a descriptive filename
   - Follow the template below
   - Add it to this folder

4. **Submit a PR**
   - Add your exercise file
   - Update this README to list it
   - Explain the learning objectives

## Exercise Ideas

Here are some ideas for future exercises:

- **Merge Conflict Simulator**: Two people edit the same lines
- **Git History Detective**: Use `git log` and `git blame` to solve a mystery
- **Branch Strategy Practice**: Implement a feature using proper branching
- **Rebase Practice**: Reorder and squash commits
- **Git Bisect Exercise**: Find which commit introduced a "bug"
- **Stash Workflow**: Practice saving and applying work in progress
- **Cherry-Pick Challenge**: Apply specific commits to different branches
- **Tag and Release**: Practice creating releases with tags

## Difficulty Levels

We use these levels to help learners choose appropriate exercises:

- 🌱 **Beginner**: New to Git, first few contributions
- 🌿 **Intermediate**: Comfortable with basic workflow, ready for branching strategies
- 🌳 **Advanced**: Experienced with Git, learning complex operations

## Tips for Success

1. **Don't rush** - Take time to understand each step
2. **Experiment** - It's okay to make mistakes here!
3. **Ask questions** - Open an issue if you're stuck
4. **Help others** - Review PRs from other learners
5. **Have fun** - Learning should be enjoyable!

## Getting Help

Stuck on an exercise? Here's what to do:

1. **Check [RESOURCES.md](../RESOURCES.md)** for Git references
2. **Review [GETTING_STARTED.md](../GETTING_STARTED.md)** for basics
3. **Search existing issues** - someone may have had the same question
4. **Open a new issue** - describe what you tried and what happened
5. **Ask in discussions** - connect with other learners

## Contributing

All exercises should:
- ✅ Have clear learning objectives
- ✅ Include step-by-step instructions
- ✅ Define success criteria
- ✅ Be safe to attempt (no destructive operations without warnings)
- ✅ Be beginner-friendly or clearly marked as advanced
