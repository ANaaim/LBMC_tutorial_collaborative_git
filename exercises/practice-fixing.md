## Git Basics

Git is a version controll system created by Linus Torvalds in 2005. It allows multiple people to work on the same project simutaneously without interfering with each others work.

### Key Concepts

**Repository**: A folder that contain your project and its history.

**Commit**: A snapshot of you're project at a specific point in time.

**Branch**: An independent line of development. The default branch is usually called master or main.

### Basic Commands

Here are some basic Git commands:

- `git init` - Initalize a new repository
- `git clone` - Clone an existing repositry
- `git add` - Stage changes
- `git commit` - Save a snapshot
- `git push` - Upload to remote server

### Fun Facts

Did you know that Git was created in just 2 weeks? Linus Torvalds needed a new version control system for the Linux kernel development after the previous system became unavailable.

GitHub, the popular hosting service for Git repositories, was founded in 2010. It has since become the largest host of source code in the world, with over 100 million repositories!

## What to Do After Fixing

After you've fixed all the mistakes:

1. Check your changes: `git diff`
2. Stage your fixes: `git add exercises/practice-fixing.md`
3. Commit: `git commit -m "Fix spelling, grammar, and formatting mistakes"`
4. Push: `git push origin fix-mistakes-yourname`
5. Create a PR describing what you fixed!

Remember: In real projects, you might not always know if something is wrong. Don't hesitate to ask questions or look things up!
